    Tentang Aplikasi

    Scout Management System (SMS) v1.1 dirancang eksklusif untuk menyederhanakan administrasi pangkalan kepramukaan. Mengintegrasikan teknologi absensi pintar QR Code, rekap digital, serta penerbitan dokumen instan.

    Akun Peserta (Multi-Role)

    Aktifkan agar peserta bisa login sendiri pakai ID Peserta (mis. P01) + password. Mereka bisa cetak ID Card, sertifikat, lihat data sangga, dan rekap absen — namun data tetap tersinkron dengan admin via Jsonbin.io.

    Dipakai untuk peserta yang belum punya password pribadi (field password di form Anggota kosong). Untuk keamanan, sebaiknya mintalah peserta mengganti password pribadi mereka, atau set password unik per peserta di form Anggota.

    Cara Login Peserta

    1. Buka aplikasi di perangkat peserta (atau via link yang dibagikan)
    2. Masukkan ID Peserta sebagai username (mis. P01)
    3. Masukkan password pribadi atau password default di atas
    4. Peserta otomatis melihat data diri sendiri + menu terbatas

    Setiap perubahan yang peserta simpan akan otomatis ter-push ke cloud (jika auto-sync aktif), jadi admin bisa lihat update-an terbaru.
